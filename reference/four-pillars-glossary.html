Four pillars — glossary

چهار ستون — واژه‌نامه

Shared vocabulary for this curriculum. Pillar names follow Yar’s architecture; industry sources often use overlapping terms (runtime, agent loop, memory, evals).

واژگان مشترک این دوره. نام ستون‌ها از معماری یار می‌آید؛ منابع صنعتی اغلب واژه‌های هم‌پوشان دارند (runtime، حلقهٔ عامل، حافظه، ارزیابی).

Pillars

ستون‌ها

Harness / Gateway · درگاه

Moves text in and out. No reasoning. In Yar: CLI (yar/gateway/cli.py) and the dashboard SPA talking to the REST API.

متن را وارد و خارج می‌کند؛ استدلال نمی‌کند. در یار: CLI و داشبورد SPA که با API حرف می‌زند.

Loop · حلقه

Reason → act → observe until the model replies or hits max iterations. In Yar: yar/loop/agent.py (run_loop).

استدلال ← عمل ← مشاهده تا پاسخ مدل یا سقف تکرار. در یار: run_loop.

Memory · حافظه

Durable state beyond one LLM call: semantic facts, episodic events, procedural skills (SKILL.md), plus a retrieval gate and consolidation. In Yar: yar/memory/ + SQLite.

حالت پایدار فراتر از یک فراخوانی مدل: حقایق معنایی، رویدادهای اپیزودیک، مهارت‌های رویه‌ای، به‌همراه دروازهٔ بازیابی و تجمیع. در یار: yar/memory/ و SQLite.

Eval / LLM-Ops · ارزیابی و عملیات

Tracing, dashboards, and release checks. Yar splits deterministic evals (0/1: did the right tool fire?) from judge evals (scored quality) and never mixes them.

ردیابی، داشبورد، و دروازهٔ انتشار. یار ارزیابی قطعی را از ارزیابی داور جدا می‌کند و هرگز مخلوطشان نمی‌کند.

Related terms

اصطلاحات وابسته

Working memory · حافظهٔ کاری

Per-turn prompt contents (system + recent history + user message). Ephemeral; rebuilt each turn in Session / Yar.respond().

محتوای پرامپت هر نوبت. موقت است و هر نوبت دوباره ساخته می‌شود.

Tool / function call · ابزار

Model-requested side effect executed by your code; result is fed back into the loop as a role: tool message (OpenAI wire format in Yar).

اثر جانبی‌ای که مدل درخواست می‌کند؛ کد شما اجرا می‌کند و نتیجه را به حلقه برمی‌گرداند.

Retrieval gate · دروازهٔ بازیابی

Cheap decision: “does this turn need durable memory?” Avoids stuffing irrelevant facts into every prompt.

تصمیم ارزان: «آیا این نوبت به حافظهٔ پایدار نیاز دارد؟» تا حقایق نامرتبط وارد هر پرامپت نشوند.

Agent (industry sense) · عامل

Per Anthropic: systems where an LLM dynamically directs tool use from environmental feedback in a loop — not a fixed workflow alone. Source: Building effective agents.

به‌تعریف Anthropic: سامانه‌هایی که مدل با بازخورد محیط، استفاده از ابزار را در یک حلقه هدایت می‌کند — نه فقط یک گردش‌کار ثابت.
