منبع: backend/yar/loop/agent.py · ARCHITECTURE.md §3

Skeleton

اسکلت

while not done:
    response = llm(messages, tools)     # reason
    if response asks for tools:
        results = run(tool_calls)       # act
        messages += results             # observe
    else:
        done                            # reply to human

Two guardrails

دو حفاظ

  1. No tool_calls → natural end; return message.content. بدون tool_calls → پایان طبیعی؛ برگرداندن message.content.
  2. max_iterations → hard stop; never spin forever. max_iterations → توقف سخت؛ حلقه تا ابد نچرخد.

Yar specifics

ویژگی‌های یار

  • Wire format: OpenAI chat.completions (role: tool, tool_calls).
  • فرمت سیم: OpenAI chat.completions.
  • messages mutated in place = traced working memory after the call.
  • messages درجا عوض می‌شود = حافظهٔ کاری ردیابی‌شده.
  • Observer for live UI + tracing — not part of loop logic.
  • Observer برای UI زنده و ردیابی — داخل منطق حلقه نیست.
  • Entry: run_loop() → LoopResult(reply, tool_calls, iterations).
  • ورودی: run_loop() → LoopResult.
