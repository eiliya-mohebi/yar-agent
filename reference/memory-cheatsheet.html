Two heroes

دو قهرمان

  • Retrieval gate — cheap model: retrieve? + query. Fails open. دروازهٔ بازیابی — مدل ارزان: بازیابی؟ + کوئری. شکستِ باز.
  • Consolidation — when unconsolidated rows ≥ every * 2, distill facts + one episode. Loss-safe. تجمیع — وقتی ردیف‌های تجمیع‌نشده ≥ every * 2، حقایق + یک اپیزود. ایمن در برابر ازدست‌رفتن.

Working vs durable

کاری در برابر پایدار

Working memory = this turn’s prompt window (Session). Durable memory = facts/episodes/skills that survive across turns. Industry parallel: session context vs long-term memory (OpenAI memory & compaction).

حافظهٔ کاری = پنجرهٔ پرامپت این نوبت. حافظهٔ پایدار = حقایق/اپیزودها/مهارت‌ها.
