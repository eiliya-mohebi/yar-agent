Memory is durable state — with a gate

حافظه حالت پایدار است — با یک دروازه

The loop’s messages list is working memory for one turn. Agents that feel personal also need durable memory across turns — without stuffing the whole database into every prompt. Yar’s answer lives in yar/memory/ + one SQLite file (ARCHITECTURE.md §6).

لیست messages حلقه، حافظهٔ کاری یک نوبت است. عاملِ شخصی به حافظهٔ پایدار هم نیاز دارد — بدون ریختن کل دیتابیس در هر پرامپت.

سه گونه حافظهٔ پایدار

Hero #1 — the retrieval gate

قهرمان ۱ — دروازهٔ بازیابی

Default-on retrieval is slow and biases answers with irrelevant facts. A small model answers: does this message need the user’s memory? (retrieval_gate.py docstring — “hero moment #1”.)

بازیابی همیشگی کند است و پاسخ را با حقایق نامرتبط منحرف می‌کند. یک مدل کوچک می‌پرسد: آیا این پیام به حافظهٔ کاربر نیاز دارد؟ 

# memory/__init__.py — gated_retrieve (abbreviated)
retrieve, query, reason = retrieval_gate.should_retrieve(
    self.client, self.settings.small_model, message
)
if not retrieve:
    return ""
found = self.facts.search(query, self.settings.retrieval_top_k)
found += self.episodes.search(query, top_k=3)
return "\n".join(found)

Fails open: parse/LLM error → retrieve anyway (“a stale memory beats a lost one” — gate module comment). JSON keys stay English; the query stays in the user’s language so FTS can match Persian facts (§7).

شکستِ باز: خطا → باز هم بازیابی کن. کلیدهای JSON انگلیسی می‌مانند؛ query به زبان کاربر می‌ماند تا FTS حقایق فارسی را بیابد (§۷).

Skill: would the gate retrieve?

مهارت: دروازه بازیابی می‌کند؟

From the gate prompt’s rule of thumb: general knowledge / math / small talk → skip; user’s life, people, plans, history → retrieve.

قاعدهٔ سرانگشتی پرامپت دروازه: دانش عمومی / ریاضی / گپ → رد؛ زندگی، افراد، برنامه‌ها، تاریخچهٔ کاربر → بازیابی.

Hero #2 — consolidation

قهرمان ۲ — تجمیع

After the reply, Yar.respond() calls memory.maybe_consolidate(). When unconsolidated chat_log rows ≥ consolidate_every * 2 (default 6 → trigger at 12 rows), a small model distills facts[] + one episode, then marks rows consolidated. Loss-safe: on failure, leave rows unmarked — chat is not deleted (§6).

بعد از پاسخ، maybe_consolidate() صدا زده می‌شود. وقتی ردیف‌های تجمیع‌نشده به آستانه برسند، مدل ارزان حقایق + یک اپیزود می‌سازد. ایمن در برابر ازدست‌رفتن: اگر شکست خورد، ردیف‌ها علامت نمی‌خورند.

Procedural memory (skills)

حافظهٔ رویه‌ای (مهارت‌ها)

Skills are not retrieved by the gate. They match by keyword overlap on name + description via text.tokens() — Unicode, bilingual stopwords, overlap ≥ 2, top 2. Descriptions must carry Persian and English triggers or فارسی silently fails to match (§7).

مهارت‌ها از دروازه عبور نمی‌کنند. با هم‌پوشانی کلیدواژه روی name + description جور می‌شوند — یونیکد، stopword دوزبانه، ≥ ۲، حداکثر ۲. توضیحات باید محرک فارسی و انگلیسی داشته باشند وگرنه فارسی خاموش شکست می‌خورد (§۷).
