Every serious agent has four pillars

هر عامل جدی چهار ستون دارد

You already know chat completions and tool calling. This lesson names the four parts that turn a model call into an agent system — and shows where each lives in Yar, a local-first teaching implementation.

شما chat completions و tool calling را می‌شناسید. این درس چهار بخشی را نام می‌برد که یک فراخوانی مدل را به سامانهٔ عامل تبدیل می‌کنند — و نشان می‌دهد هر کدام در یار کجا زندگی می‌کند.

What “agent” means here

اینجا «عامل» یعنی چه

Anthropic’s practical definition: agents are systems where an LLM dynamically directs tool use from environmental feedback in a loop — not only a fixed workflow hardcoded in advance. (Building effective agents, Dec 2024.)

تعریف کاربردی Anthropic: عامل سامانه‌ای است که مدل با بازخورد محیط، استفاده از ابزار را پویا در یک حلقه هدایت می‌کند — نه فقط یک گردش‌کار ازپیش‌ثابت. (Building effective agents)

One turn, all four pillars

یک نوبت، هر چهار ستون

مونتاژ در Yar.respond() است. درگاه یک رشته می‌دهد؛ بقیه همکاری ستون‌هاست:

Real code (abbreviated from backend/yar/app.py):

کد واقعی (خلاصه از backend/yar/app.py):

# Gateway called respond() with a user string
system = self.session.build_system(user_message, notify=notify)
messages = (
    [{"role": "system", "content": system}]
    + self.session.history[-window:]
    + [{"role": "user", "content": user_message}]
)

result = run_loop(  # ← Loop pillar
    client=self.client,
    model=self.settings.model,
    messages=messages,
    tools=self.tools,
    max_iterations=self.settings.max_iterations,
    observer=notify,
)

self.session.add_exchange(...)       # persist chat
self.memory.maybe_consolidate(...)   # ← Memory pillar
# Tracer wraps the turn                   ← Eval / Ops pillar

Inside the loop (backend/yar/loop/agent.py), the two guardrails match industry advice on stop conditions:

داخل حلقه، دو حفاظ توقف همان توصیهٔ صنعتی دربارهٔ شرط پایان است:

for iteration in range(1, max_iterations + 1):
    response = completions.create(...)   # reason
    tool_calls = message.tool_calls or []
    if not tool_calls:
        return reply                   # natural end
    for call in tool_calls:
        output = tools.execute(...)      # act
        messages.append({..., "content": output})  # observe
# else: hit max_iterations → hard stop
