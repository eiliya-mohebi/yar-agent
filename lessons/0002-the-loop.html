The loop is the whole trick

حلقه همان کل ترفند است

Frameworks add indirection. Underneath, every agent turn is reason → act → observe with two exits. Yar keeps that in ~95 lines: backend/yar/loop/agent.py.

فریم‌ورک‌ها لایه اضافه می‌کنند. زیرشان، هر نوبت عامل استدلال ← عمل ← مشاهده است با دو خروجی. یار همان را در حدود ۹۵ خط نگه می‌دارد.

    What the loop deliberately is not

    حلقه عمداً چه چیزی نیست

    It does not load SOUL.md, search memory, or write traces. Those sit in Session / Memory / Tracer. An Observer callback lets the gateway and ops watch events without owning the loop (§3). That separation is the point of the four pillars.

    حلقه SOUL را بار نمی‌کند، حافظه را جستجو نمی‌کند، و ردیابی نمی‌نویسد. آن‌ها در Session / Memory / Tracerاند. Observer فقط تماشا می‌کند — بدون مالک شدن حلقه.
